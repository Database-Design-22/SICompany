# 시연 데이터

`docker/init/03_dummy.sql`을 처음 적재한 상태 기준이다. 기준일은 2026-11-24.
시연 중에 데이터가 바뀌면 `docker` 폴더에서 `docker compose down -v` 후 `docker compose up -d`로 되돌린다.

다른 EXE 직원은 10-0001 강서연이다.

## 4. '작성중' 평가와 메모가 남은 평가자 (평가 제출 시연)

평가자 **25-0001 김직수**는 프로젝트 **P26-004 마루물류 모바일 앱 개발**(종료 2026-09-23)에서 동료평가를 맡았다.

| 평가ID | 피평가자 직원ID | 이름 | 내 메모 | 문항 점수 입력 수 |
| --- | --- | --- | --- | --- |
| 1495 | 21-0002 | 김준엽 | 있음 (MEMO_ID 36) | 5 / 7 |
| 1497 | 18-0001 | 오하준 | 있음 (MEMO_ID 39) | 3 / 7 |
| 1494 | 15-0001 | 홍채원 | 없음 | 7 / 7 |
| 1496 | 19-0007 | 정서준 | 없음 | 0 / 7 |
| 1498 | 19-0001 | 김하준 | 없음 | 0 / 7 |

- 동료평가 문항은 PEER_USE_YN = 'Y'인 7개다.
- 시연 흐름은 평가 1495(김준엽)를 연다 → 메모 36이 보인다 → 점수와 내용을 채워 제출한다 → 메모 36이 삭제된다.
- 제출하면 EVAL_DT가 2026년이 되므로, 보정점수 화면에는 "확정 전"으로 나온다. 2026 회차가 미확정이기 때문이다.

## 5. '접수' 교체 요청 (교체 요청 → 수용 → 제외 등록 → 배정 후보)

| 항목 | 값 |
| --- | --- |
| 교체요청ID | 10 |
| 요청일자 / 사유 | 2026-11-08 / 커뮤니케이션 방식에 대한 고객사 불만 |
| 발주처 / 요청 담당자 | 3 (주)다온전자 / MGR_ID 3 임수아 |
| 대상 이력 | PRJ_HIST_ID 334 (2026-07-06 ~, 열림) |
| 대상 직원 | **17-0001 조민경** (직무 PG) |
| 대상 프로젝트 | **P26-007 다온전자 API 게이트웨이 구축** (진행) |
| 같은 발주처의 다른 진행 프로젝트 | **P26-011 다온전자 클라우드 전환** (진행, PM 12-0001 송수아) |

- 시연 흐름: 요청 10을 수용한다 → 조민경을 발주처 3에 '제외'로 등록한다 → P26-011의 배정 후보 목록을 연다.
- 후보 목록에서는 조민경에게 경고와 근거(교체요청 10, 담당자 임수아)가 함께 보인다.
- 수용 전에는 조민경이 P26-007에 투입 중이라 후보 목록에 나오지 않는다. 수용하면 이력이 닫혀 후보에 나온다.
- 발주처 3에는 지금 지정인력이 없으므로 겹치는 지정 때문에 막히지 않는다.
- 후임 후보는 지금 투입 중이 아닌 재직 개발직원이다(32명). 예: 11-0002 서수빈, 11-0004 장준서, 14-0002 서상우.
- 예비 데이터로 요청 11도 '접수' 상태다. 대상은 16-0004 권유준(PL), 프로젝트는 P26-002 라온제약 물류 관리 시스템 개발(지연), 담당자는 최지호다.

## 확인용 SELECT

```sql
-- 3. P26-013 팀원
SELECT h.EMP_ID, e.EMP_NM, pt.ROLE_ID, h.STRT_DT
FROM TB_PRJ_HIST h
JOIN TB_EMP e ON e.EMP_ID = h.EMP_ID
JOIN TB_PRJ_PTCP pt ON pt.EMP_ID = h.EMP_ID AND pt.PRJ_ID = h.PRJ_ID
WHERE h.PRJ_ID = 'P26-013' AND h.END_DT IS NULL;

-- 4. 김직수의 작성중 평가와 메모
SELECT e.EVAL_ID, e.EVLTE_EMP_ID, e.EVAL_STAT, m.MEMO_ID
FROM TB_EVAL e
JOIN TB_PEER_EVAL pe ON pe.EVAL_ID = e.EVAL_ID
LEFT JOIN TB_EVAL_MEMO m
       ON m.WRTR_EMP_ID = pe.EVLTR_EMP_ID
      AND m.TRGT_EMP_ID = e.EVLTE_EMP_ID
      AND m.PRJ_ID = e.PRJ_ID
WHERE pe.EVLTR_EMP_ID = '25-0001' AND e.EVAL_STAT = '작성중';

-- 5. 접수 상태 교체 요청
SELECT r.REPL_REQ_ID, r.PROC_STAT, h.EMP_ID, h.PRJ_ID, h.END_DT
FROM TB_STAFF_REPL_REQ r
JOIN TB_PRJ_HIST h ON h.PRJ_HIST_ID = r.REPL_TRGT_HIST_ID
WHERE r.PROC_STAT = '접수';
```
